# 🤖 AI Web Scraper Agent

An AI-powered autonomous web scraping system capable of extracting structured data from websites using natural language prompts.

## 🚀 Overview

AI Web Scraper Agent is an intelligent scraping application that automates data extraction from websites. Users can provide prompts in plain English, and the agent extracts relevant information efficiently.

The project is designed for scalable and automated scraping workflows using Python-based tooling.

---

# ✨ Features

* 📱 Extract product name, price, rating, and product URL
* 🌐 Scrape data from e-commerce websites like Flipkart
* 🧠 Natural language query-based scraping
* ⚡ Automated structured data extraction
* 📦 Lightweight and modular architecture
* 🔄 Easily extensible scraping workflow
* 📄 Clean Python implementation

# ⚙️ Installation

## 1️⃣ Clone Repository

```bash
git clone https://github.com/Kamaraj11/ai-web-scraper-agent.git
```

## 2️⃣ Navigate to Project Folder

```bash
cd ai-web-scraper-agent
```

## 3️⃣ Create Virtual Environment

```bash
python -m venv venv
```

## 4️⃣ Activate Virtual Environment

### Linux / WSL

```bash
source venv/bin/activate
```

### Windows

```bash
venv\Scripts\activate
```

## 5️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

# ▶️ Usage

Run the application:
